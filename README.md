# 李亦凡的个人主页

这里是李亦凡的个人主页。

## 部署

GitHub Actions 会将 Jekyll 主页与
[`USTC-AI-Notes`](https://github.com/LUNARKN1GHT/USTC-AI-Notes) 构建的静态笔记站合并发布。
笔记总目录位于 [`/notes/`](https://lunarkn1ght.github.io/notes/)，其中课程笔记发布到
[`/notes/USTC-AI-Notes/`](https://lunarkn1ght.github.io/notes/USTC-AI-Notes/)。内容每日自动同步，也可在 Actions 页面手动触发。

首次使用时，需在仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为
**GitHub Actions**。
